# Bắt đầu với Diro

Mục này đưa bạn đi từ lúc chưa có tài khoản tới lúc AI bắt đầu trả lời khách trên Fanpage. Làm lần lượt theo thứ tự dưới đây là xong:

1. [Đăng nhập Diro](./dang-nhap.md) — bằng tài khoản Facebook, tài khoản Master hoặc tài khoản nhân viên.
2. [Bảng điều khiển](./bang-dieu-khien.md) — màn hình đầu tiên sau khi đăng nhập, nơi hiện mọi trang bạn đang quản lý.
3. [Kết nối thêm trang](./them-trang.md) — đưa thêm Fanpage Facebook hoặc Zalo OA vào Diro.
4. [Tạo Chat Agent và bật AI](./kich-hoat-ai.md) — tạo "nhân viên AI" cho trang rồi bật tự động trả lời.

:::tip Gợi ý
Trước khi bật AI, bạn nên thêm sản phẩm và viết vài mệnh lệnh cho AI, rồi **Chat thử** xem AI trả lời có đúng ý không. Chi tiết ở mục **Chat Agent (AI trả lời tin nhắn)**.
:::
